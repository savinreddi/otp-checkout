# Prompts given to the LLM (Claude) while building this application

This project was built with Claude (Anthropic). Below is the full list of
prompts given, in order.

## Prompt 1

Uploaded the assignment brief 
along with the note:

> * React → Frontend UI development
> * Go (Golang) → Backend/API development
> * PostgreSQL → Relational database

## Prompt 2

> create an full stack project in zip file

## Prompt 3

> Set up the OTP checkout project with distinct React frontend, Go API, and
> PostgreSQL database layers. Implement registration with a generated 6-digit
> OTP, background email recognition during checkout, OTP login with a skip
> option, logged-in user display, and checkout persistence.

## Prompt 4

> Explain how to install the project prerequisites and run the frontend,
> backend, and PostgreSQL database locally on Windows.

## Prompt 5

> Add a reproducible local PostgreSQL setup using Docker Compose, document the
> required DATABASE_URL, ALLOWED_ORIGIN, and VITE_API_URL environment
> variables, and verify the frontend build.

## Prompt 6

> Explain how to create the PostgreSQL schema in Supabase and connect the Go
> backend to the hosted database without exposing database credentials.

## Prompt 7

> Explain how to deploy the React frontend to Vercel and the Go backend to
> Render, including the required build commands, start command, environment
> variables, CORS configuration, health check, and redeployment steps.

## Prompt 8

> Troubleshoot the Render database connection error, use the Supabase Session
> Pooler connection string when the direct IPv6 connection is unreachable, and
> verify that the deployed API connects to PostgreSQL.
